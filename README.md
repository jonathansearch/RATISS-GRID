## 🎯 Why Priority 0

A non-cryogenic quantum processor, a biochemical incubator at ±0.1 °C or a
compute cluster require a **power purity** that the public grid (Eneo) does not
provide: micro-outages, voltage sags, harmonic noise. Electrical noise
destroys quantum coherence, skews biological measurements and fries low-cost
electronics. **Without this building block, everything else is useless.**

RATISS-GRID sizes and validates *in silico* an **Active Power Conditioner
(APC)** before buying a single component:

```
Mono PV panels → MPPT → [ LiFePO4 ‖ Supercapacitors ] → Pure sine inverter → Critical load
                              ▲
                     RATISS topological detection
```

The **supercapacitors** absorb micro-outages in milliseconds, the time for the
**LiFePO4 battery** to take over without interruption. The Eneo grid is only a
top-up — not a dependency.

## 📐 The founding law applied to the grid

$$R = P_{sig} \qquad\qquad \Delta W = \eta \cdot \varphi \cdot P_{sig} \cdot C$$

The electrical grid is modeled as a **dynamic topological graph**: nodes
are sources and loads, edges are lines. The **P_sig persistence signature**
(H1 homology, Vietoris-Rips) of the cloud of time-series voltages measures the
**structural fragility** of the grid — and serves as an early-warning trigger
for the supercapacitor → battery switchover. We certify the **form** of the
grid, not just its amperes.

│   ├── perturbations.py   # Library of realistic fault scenarios

## 🚀 Quick start

```bash
git clone https://github.com/samajonathan9-source/ratiss-grid.git
cd ratiss-grid
pip install -e .

# Size a vault for a 2 kW critical load over 30 days
python -m ratiss_grid.size_my_grid --load 2000 --days 30

# Monte Carlo: 1000 climate scenarios → availability rate
python -m ratiss_grid.size_my_grid --load 2000 --days 30 --monte-carlo 1000
```

Minimal dependency: `numpy`. Tests: `pytest tests/ -q`.

## 🔬 Reference configurations

| Config | Critical load | Usage | Estimated budget |
|---|:---:|---|---:|
| **Minimal** | 500 W | Photonic QPU bench + control PC | 2–3 M FCFA |
| **Standard** ⭐ | 2 kW | QPU + bio incubator + workstation | 5–8 M FCFA |

remains configurable for all three.
